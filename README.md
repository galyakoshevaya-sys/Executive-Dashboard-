# Executive Dashboard

Дашборд керівника напрямків: аналітика DESIGN & SUPPORT (Planner) і UX/UI (Jira), плюс заготовка вкладки успішності проєктів.

## Як користуватись

Відкрийте `index.html` у браузері (подвійний клік, або `git pull` + відкрити файл локально).

Весь парсинг Excel-файлів і вся аналітика працюють прямо в браузері — на кожній аналітичній вкладці є кнопка/дропзона для завантаження нових експортів (кілька файлів одразу, або перетягуванням). Дані нікуди не відправляються, обробка повністю локальна.

- **DESIGN & SUPPORT** — вивантажте з Planner: аркуш «Консолидированные данные» (Export → Excel).
- **UX/UI** — вивантажте з Jira: Issue Navigator → Export → «Better Excel (All fields)». Можна одразу кілька файлів (наприклад, якщо вигрузка розбита на частини) — вони об'єднаються автоматично.

## GitHub Pages (опційно)

Якщо захочете живу веб-адресу замість локального файлу — Settings → Pages → Source: `main` branch, `/ (root)`. Репозиторій приватний, тож посилання буде доступне тільки після авторизації в GitHub (або потрібен платний план для приватних Pages).
